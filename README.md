# I’Lek Powell's Portfolio

## Project Pages

This portfolio has three pages:

- Home (`index.html`)
- My Projects (`projects.html`)
- About/Contact (`about.html`)

## Accessibility Improvements

I made changes to help make my website easier for everyone to use.

- Added skip links so visitors can go directly to the main content.
- Added labels to the contact form so visitors know what information to enter.
- Added a fieldset and legend to organize the contact information.
- Added error messages to show visitors when information is missing or incorrect.
- Added keyboard focus styles to make navigation easier.
- Added alternative text to the Home page image.
- Added page titles and organized headings to make the pages easier to understand.
- Added autocomplete to the name and email fields.

## Gestalt Principles

### 1. Proximity

I used proximity by placing the project cards close together under the My Projects heading. This helps visitors understand that the projects belong in the same group.

### 2. Similarity

I used similarity by giving the project cards the same colors, spacing, and layout. This makes the website look organized and helps visitors recognize that the cards are related.

## Contact Form

I added a contact form to my About/Contact page. It asks visitors for their name, email address, and message. JavaScript checks the information and displays error messages if something is missing or incorrect.

The form is for demonstration purposes and does not send messages.
