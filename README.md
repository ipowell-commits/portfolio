# I’Lek Powell's Portfolio

## My Website

This portfolio shares information about me, my school projects, and the technology skills I am learning.

## Accessibility Improvements

- I added page titles and language declarations to all three pages.
- I added labels to the contact form fields.
- I added a fieldset and legend to organize the contact information.
- I added error messages to help users correct mistakes.
- I added keyboard-friendly navigation and visible focus styles.
- I used semantic HTML elements to organize the pages.
- I used consistent colors throughout all three pages.

## Gestalt Principles

**1. Proximity**

I used proximity to group my project cards and keep related information together.

**2. Similarity**

I used similarity by keeping the same colors, headings, and card styles throughout my website.
